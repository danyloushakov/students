# Team project — New Era

Спільна папка команди. Працюємо через Sourcetree.

## Структура

```
team-project/
├─ MASTER.psd          ← майстер-файл: лише збирає роботи (редагує тільки ведучий)
├─ students/
│  ├─ anna.psb         ← кожен редагує ЛИШЕ свій файл
│  ├─ bohdan.psb
│  └─ ...
├─ master-assets/      ← PNG, які генерує Photoshop (File → Generate → Image Assets)
├─ index.html          ← сторінка команди (вкладка «Результат команди» на сайті)
└─ style.css
```

## Правила команди

1. Перед роботою — **Pull**.
2. Редагуй **лише свій** файл `students/<ім'я>.psb`.
3. Зберіг → **Stage All** → опис «Ім'я: що змінив» → **Commit** → **Push**.
4. `MASTER.psd` і `master-assets/` оновлює лише ведучий (викладач або капітан команди).
5. Файли до 50 МБ. Великі фото — зменш перед тим, як вставляти.
6. Конфлікт? Не панікуй: Resolve Using ‘Theirs’ і скажи ведучому.
