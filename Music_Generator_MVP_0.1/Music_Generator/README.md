# Music Generator — MVP 0.1

## Запуск у браузері
1. Розпакуйте архів.
2. Відкрийте `index.html` у Chrome або Edge.
3. Натисніть **Generate music**, потім **Прослухати**.

Інтернет для роботи генератора не потрібен після завантаження файлів (шрифт може використовувати системний fallback).

## Що вже працює
- 7 стилів: Acoustic Jam, World Percussion, Funk Groove, Latin Pulse, Ambient, Indie Rock, Electronic.
- Генерація ритм-секції, джембе, гітари, басу та мелодії.
- BPM, тривалість, насиченість, варіативність, тональність.
- Відтворення через Web Audio API.
- Експорт WAV та MIDI.

## Windows
Ця версія працює у Chrome/Edge на Windows. Для окремого `.exe` наступним кроком додамо Electron-обгортку та інсталятор. Сам по собі цей архів ще не є Windows-інсталятором.

## Обмеження MVP
Звуки зараз синтезуються програмно, це чорнові тембри, а не професійні семпли реальних інструментів. Наступний етап — замінити/доповнити тембри якісними ліцензованими семплами, покращити музичну гармонію, структуру куплет/приспів та мікшер.
